# 版本来源

本目录为 nano-code 0.2 的独立实现版本，采用新的 Python 包、测试、Vue 源码和构建配置，不导入或运行旧版 MiniCode 实现。

旧版 nano-code 的提交记录、原有许可和来源说明应随归档分支保留。本版的 MIT 许可覆盖本版发布的项目代码；第三方库遵循其各自许可。GitHub Contributors 根据默认分支的提交记录生成，修改 README 不会更改贡献者统计。

旧版已完整归档至 [`codex/archive-main-before-independent-20261022`](https://github.com/leonbuilds-ai/nano-code/tree/codex/archive-main-before-independent-20261022)。经维护者确认，`main` 使用本版独立提交历史；归档分支保留旧版的来源与许可说明。
